# 🚦 Traffic Sign Recognition — PyTorch + YOLO + Streamlit

A complete **trainable two-stage traffic-control recognition project**:

1. **YOLO detector** finds bounding boxes for road signs and annotated traffic lights in a full road image.
2. **Your own PyTorch CNN**, implemented with `torch.nn.Module`, classifies each cropped object.
3. A **Streamlit localhost app** draws boxes and shows sign names and confidence scores.
4. `TrafficSignRecognition.ipynb` implements the assignment requirements: data exploration, preprocessing, splits, custom network, forward pass, training loop, validation, test Accuracy/F1, plots, and a demonstration. **Running training is required before it can recognize signs.**

## 1. Install (Windows PowerShell, Python 3.10–3.12 recommended)

```powershell
cd TrafficSignRecognition
py -3.11 -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

If your machine has an NVIDIA GPU, use the [official PyTorch installation selector](https://pytorch.org/get-started/locally/) for the correct CUDA build. CPU works but detector training can be very slow.

On macOS or Linux, create/activate the environment with `python3 -m venv .venv` and `source .venv/bin/activate`.

## 2. Prepare data from BOTH archives

```powershell
python prepare_data.py --gtsdb "archive (2).zip" --roboflow "archive (1)(1).zip"
```

Or run the preprocessing cell in the notebook. Preprocessing is idempotent: if `data/summary.json` already exists, the notebook reuses it. To rebuild after changing sources, **delete the generated `data/` folder first**.

The two source datasets have different numeric class IDs. This project reads Roboflow's exact names from `car/data.yaml` and uses the standard GTSDB 0–42 mapping, merging common labels by **name** (e.g., "Stop", "Speed Limit 50"). Unsupported GTSDB test class `100` is *excluded from classification scoring*, while its box is retained for detector evaluation. Classes without a training example are excluded from the classifier. The full merged classifier label count is determined from *training* examples.

Source provenance:
- [German Traffic Sign Detection Benchmark (GTSDB)](https://benchmark.ini.rub.de/gtsdb_dataset.html), 600 original train / 300 original test road images; original train is divided into training + validation (seed 42).
- [Self-Driving Cars — Roboflow dataset](https://universe.roboflow.com/selfdriving-car-qtywx/self-driving-cars-lfjou/dataset/6), 3,530 train / 801 validation / 638 test images. Dataset README states **CC BY 4.0** and has a 15-class YOLO export.

**Test images are never used for training or hyperparameter selection.** A small number of original images may be similar between Roboflow train and test subsets; this limits how much benchmark accuracy implies performance on unrelated web photos.

## 3. Train the custom CNN

The notebook contains the *complete PyTorch CNN architecture and explicit epoch training loop* so you can explain them at your defense. You can also train from PowerShell:

```powershell
python train_classifier.py --epochs 15 --batch 64
```

This produces `models/sign_classifier.pt`, `models/classifier_learning_curves.png`, and test Accuracy/F1 metrics. A CPU can train the classifier, but a GPU will be faster.

If the included initial classifier weights need improvement, continue CNN training (optimizer restarts) instead of overwriting them from scratch:

```powershell
python train_classifier.py --init-checkpoint "models/sign_classifier.pt" --epochs 12
```

This is still a **training project**, and you should use the test metric output to evaluate how much your own training improves it.

**Caution:** Some GTSDB categories have only 1–3 training boxes. These cannot be expected to generalize well. Speed-limit classes and "Stop" have data from both sources; rare classes need more data if performance is poor.

## 4. Train the sign detector (required for full road images)

Fine-tune a lightweight YOLO detector on **one box category**, `traffic_control_object`:

```powershell
python train_detector.py --epochs 35 --imgsz 640 --batch 8
```

For Windows users with limited CPU/RAM (slower and potentially less accurate):

```powershell
python train_detector.py --epochs 20 --imgsz 416 --batch 4 --device cpu
```

For an NVIDIA GPU, add `--device 0` (and adjust batch according to VRAM). The first run downloads `yolo11n.pt` pretrained detection weights. This is a **fine-tuned detection backbone**, not the custom CNN; your CNN is separately trained from scratch. The best trained detector will be copied to `models/sign_detector.pt`. Training logs, mAP plots, and metrics appear in `runs/traffic_sign_detector` and `models/detector_test_metrics.json`.

A trained CNN *alone* cannot place rectangles on a whole road image. **Both** `models/sign_classifier.pt` and `models/sign_detector.pt` are necessary for end-to-end recognition.

## 5. Launch your localhost website

```powershell
streamlit run app.py
```

Open **http://localhost:8501**, upload a `jpg`, `jpeg`, or `png` road image, and see marked bounding boxes and sign names. You can adjust detection/classification thresholds and download the annotated PNG. If checkpoints are missing, the app gives concrete training instructions rather than inventing predictions.

## 7. Optional third dataset larger than 512 MB

You don't need to upload the ZIP to ChatGPT. If your third dataset is already in **YOLO detection format** (with `data.yaml` containing class names and `train/images`, `train/labels` folders), extract it locally and rebuild data:

```powershell
python prepare_data.py --gtsdb "archive (2).zip" --roboflow "archive (1)(1).zip" --extra-root "C:\path\to\third_dataset"
```

If its format is COCO JSON, Pascal VOC XML, classification-only images, or its class definitions differ, **do not blindly combine the labels**. First convert/inspect it separately. Unknown class names from a compatible third dataset are added to the CNN categories if seen in *training*, while YOLO detection uses all bounding boxes as the one shared category.

## Quality and limitations

- YOLO detects candidates on the full image; CNN classifies detected crops. **Classifier F1 on ground-truth crops is not end-to-end detection+recognition accuracy.** Report detector mAP separately.
- Speed limits, stop signs, warning/directional signs, and annotated red/green traffic lights are supported to the extent represented by training examples. Unrepresented signs cannot be recognized reliably.
- Dataset signs may be tiny, occluded, blurred or country-specific. Training on German signs does not guarantee recognizing signs from other countries.
- Confidence values are model scores, not calibrated probabilities of being correct.
- The trained detector checkpoint is not supplied, because detector fine-tuning on 5,869 images has not been run here. A preliminary CNN classifier checkpoint is included, but it has low measured held-out test performance (**33.9% accuracy, weighted F1 0.284 on 1,123 known-class sign crops**). It requires substantial further training or stronger data for higher-quality recognition. These numbers are **classifier crop** scores, not detection/whole-image scores. The supplied two-point fine-tuning learning-curve plot is not the complete history of the initial CNN run. Do **not** present untrained predictions or fabricated metrics at your defense.

## Troubleshooting

| Issue | Fix |
|---|---|
| `FileNotFoundError` for ZIP | Copy both archive files into project directory or pass full paths to `prepare_data.py`. |
| `data.yaml` path wrong after moving project | Delete `data/`, run `python prepare_data.py` again. |
| `CUDA out of memory` | Lower detector `--batch`, try `--imgsz 416`. |
| Slow detector CPU training | Use a CUDA GPU/Google Colab, or a smaller image size for a quick experiment. |
| `model checkpoint missing` in app | Train both models; confirm the two `.pt` files exist in `models/`. |
| Detector finds no sign | Increase detector `image size`, lower threshold; check training metrics. |
| CNN returns wrong sign | Check class distribution, increase epochs/data, inspect crop quality and domain shift. |
| Third dataset not recognized | Check whether it has YOLO bounding boxes and `data.yaml`. |

This is a project for study/demo and should not be used to make real driving or safety decisions.
